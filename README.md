Entry for the [make.fun](https://make.fun) bounty
[The Funniest Toaster Error Message](https://make.fun/c/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

A toaster error in the shape of a real device message (ERR_CRUST) with a straight-faced absurd cause: the bread unionized with the bagels.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> ERR_CRUST: Bread refused to brown. It has unionized with the bagels and demands better heating.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
